# 时序 Chrono 使用指南

时序把「接下来该做什么」交给系统去算:你说要做什么,它排出几点几分做,并告诉你为什么这样排。数据默认只存在你自己的设备上。

## 1. 安装与打开

| 方式 | 步骤 |
|---|---|
| 最快试用 | 运行 `npm run single` 生成 `Chrono-单文件版.html`,双击用浏览器打开 |
| 本地服务 | 安装 Node.js,运行 `node tools/server.js`,打开 http://localhost:8765 。Windows 可双击 `启动.bat` |
| Windows 程序 | 见 `desktop/README.md` |
| 手机 | 部署到 https 网址后,安卓 Chrome「安装应用」,iPhone Safari「添加到主屏幕」。部署方法见 `部署到Cloudflare.md` |

## 2. 四个页面
- **今天**:顶部是「长期事项」,下面是「下一件事」大卡片、今日时间轴。点任何一块可以看到「为什么排在这里」。
- **计划**:一周视图。拖动块可以手动调整,拖的时候会实时提示代价;下方是待安排池和收件箱。
- **领域**:工作、健康、关系、学习、财务、家务六个面的每周时间预算,以及固定周程(课表)和习惯。
- **回顾**:洞察卡片、周计划执行率、时间账本,可以向助手提问。

## 3. 怎么记事情
在底部输入框直接说:
- `周三下午三点开会,一个小时,提前半小时准备` → 解析成日程,出现确认卡片,点「就这样 / 改一下 / 先放着」。
- `周五前写方案,三个小时` → 待办,系统自动排到合适的时段,并按截止日倒排。
- `每周三次健身,一小时`、`每周都要写周报,两个小时` → 周期事项,往后逐周自动安排。
- `下周三到周五出差` → 不可用日,这些天不排任务。
- 点图片按钮、粘贴或拖入截图 → 用大模型识别(需先接入,见第 6 节),可以同时写一句说明。

## 4. 长期事项
一直要做、不适合排进日程的事(背单词、联系老朋友)。常驻「今天」页顶部,按设定间隔提醒;点「做了」记一次,「明天」今天不再提醒。不会进日程,没做也不会变红或累计。输入「长期坚持背英语,每天提醒我」即可添加。

## 5. 课表与固定周程
领域页 → 固定周程 / 课表:可导入课表图片,或直接打字:`高数 周一 8:00-9:40 周三 10:00-11:40 教二301 1-16周`。支持单双周、周次、一门课每周多个时间。法定节假日(内置 2026、2027 官方安排)自动停课。调课、停课对助手说一句即可。

## 6. 大模型(可选,可完全关闭)
设置 → 大模型,选服务商,填自己的 API Key,支持 Anthropic、OpenAI、通义、智谱、本机 Ollama 及 OpenAI 兼容接口。截图识别必须选支持看图的模型。「快速模型」用于纯文字、更快更省。输入框里的 ✦ 按钮是助手:说「把周三的高数调到周四下午」,它先列出打算怎么改,你确认才执行,执行后可撤销。

## 7. 保护你的安排
- 点块 →「设为不可侵入」:此后任何自动排程都不会动它或压进它。
- 手动拖过的块、手动放置的块同样受保护。
- 会议和课程与被保护的块重叠时,页面会提示,由你决定。

## 8. 设置速查
可用时段、高精力时段、午休(可自定义起止)、留白比例、缓冲、周末时段、通勤、法定节假日是否避让、液态玻璃透明度、长期事项提醒时间。

## 9. 多设备同步
设置 → 多设备同步。数据在设备上加密后才上传,服务器只看到密文。
1. 准备同步服务:`node tools/server.js`(局域网),或部署 `tools/sync-worker.js` 到 Cloudflare Workers。
2. 第一台设备点「生成」得到同步码,其他设备填相同的服务器地址和同步码。
3. 加密要求页面是 https 或 localhost;同步码丢失后云端数据无法恢复。

## 10. 数据与隐私
- 所有数据在浏览器本地存储。设置里可导出 JSON / CSV / 日历(.ics),也可一键删除全部数据。
- API Key 只保存在你的设备上,不参与导出文件。
- 不做社交、不代办、不评判人;AI 可以完全关闭,退化成普通日历。

## 11. 常见问题
- **提醒不准时(尤其 iPhone)**:网页无法后台准点推送,请用「导出到日历」交给系统日历提醒。
- **大模型提示连不上**:部分服务商有跨域限制,用本地服务的代理(设置里「本地代理地址」填 `http://localhost:8765/proxy`),或使用 Windows 桌面版。
- **同步失败 405 / 超时**:服务器地址指向了只托管网页的站点,或网络访问不了该域名,见 `部署到Cloudflare.md`。
- **页面没更新**:强制刷新(Ctrl+F5);手机上重新添加到主屏幕。
